# Portal VPM

Site institucional estático do Portal VPM, com segmentação por perfil de organização e logotipos oficiais.

## Publicação no Cloudflare Pages

- Branch de produção: `main`
- Framework: nenhum
- Comando de build: nenhum
- Diretório de saída: `/` (raiz do repositório)

O formulário gera um briefing localmente e não envia dados a um servidor. O botão flutuante do WhatsApp está desativado.
