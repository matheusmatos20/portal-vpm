# Portal VPM

Site institucional estático do Portal VPM, com segmentação por perfil de organização e logotipos oficiais.

## Publicação no Cloudflare Pages

- Branch de produção: `main`
- Framework: nenhum
- Comando de build: nenhum
- Diretório de saída: `/` (raiz do repositório)

O formulário gera um briefing localmente e não envia dados a um servidor. O botão flutuante do WhatsApp está desativado.

## Identidade visual

O layout atual usa como referência estética a composição editorial, a tipografia marcante e o contraste de cores do site Se Cuida Preta. A fotografia do hero foi criada para este projeto; os arquivos `assets/logo-vpm-roxo.png` e `assets/logo-vpm-redondo.png` são os logotipos oficiais fornecidos pela cliente.
